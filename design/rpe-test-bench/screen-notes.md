# Screen Notes

## 1. Dashboard (Landing)
- **Purpose**: Entry point. High-level overview of projects, recent tests, and system status.
- **Key Elements**:
  - Global navigation.
  - Recent specimens tested (with pass/fail thumbnails).
  - Quick-start "New Simulation" button.
- **Aesthetic**: Clean, data-forward. Dark mode by default.

## 2. RPE Test Bench (Main Workspace)
- **Purpose**: The primary interface for running simulations.
- **Layout**: 4-pane technical layout.
  - Left: Tree view of structure components (expandable/collapsible).
  - Center: WebGL 3D Viewer. Large, unobstructed. Dark grid background.
  - Right: Context-sensitive settings and results panel.
  - Bottom: Horizontal timeline scrubber.
- **Aesthetic**: Dense, information-heavy but strictly hierarchical. Engineering software (like AutoCAD, ANSYS, or STAAD) meets modern web design.

## 3. Hazard Setup
- **Purpose**: Panel state before running a simulation.
- **Key Elements**:
  - Wind speed slider (kph).
  - Rain intensity toggle.
  - Debris type selection.
  - Run Mode dropdown (Fixed Duration, Until Breaking Point).
- **Aesthetic**: Input fields should look industrial. Use monospace fonts for numerical inputs.

## 4. Simulation Viewer (Active Run)
- **Purpose**: The visual state while a simulation is actively running.
- **Key Elements**:
  - Center viewport overlays (wind vectors, stress heatmaps).
  - Pulsing UI elements indicating active stress calculations.
  - Locked (disabled) right panel inputs.
- **Aesthetic**: High contrast. Use muted blues for environmental forces, bright warning colors (orange/red) for structural stress.

## 5. Results + Upgrade Path
- **Purpose**: Panel state after a simulation completes.
- **Key Elements**:
  - "Simulation Complete" / "Failure Detected" header.
  - List of triggered failure events with timestamps.
  - Interactive upgrade checkboxes (e.g., "Add diagonal bracing +₱3,500").
  - Dynamically updating total cost.
  - "Prototype Rebuilder" suggestion block (e.g., "Next Specimen: A1").
  - Export buttons.

## 6. Material Library (Placeholder)
- **Purpose**: A dedicated screen or modal for browsing the baseline materials and their unit costs.
- **Key Elements**:
  - Data table format (Name, Type, Cost, Physical properties).
  - Filtering and sorting.

## 7. Prototype Atlas (Placeholder)
- **Purpose**: A gallery or tree of all possible architectural permutations generated by the Prototype Rebuilder.
- **Key Elements**:
  - Lineage view (A0 -> A1 -> A2 -> B0).
  - Comparison matrices (Cost vs. Resilience).
