# RPE Test Bench Design

This directory contains the design documentation, screen notes, and prompts for generating the UI components of the FutolTech Resilience Physics Engine (RPE).

## Overview
The goal of this UI phase is to establish a visual language that feels like an **engineering cockpit**, a **disaster test lab**, and a **cost decision board**. It must move away from generic SaaS aesthetics and embrace a serious, technical, and data-dense layout.

## Contents
- `screen-notes.md`: Detailed structural breakdowns of each required UI screen.
- `stitch-prompts.md`: Text prompts formatted for generating UI mockups (e.g., using Google Stitch MCP or other UI generation tools).
