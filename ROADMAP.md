# Roadmap

## Phase 0 — Repo foundation
Docs and sample data only. Establishing the structure for future agents and developers to build upon.

## Phase 1 — Visual MVP
Basic 3D viewport, model builder placeholders, and scripted hazard animations to demonstrate the user flow.

## Phase 2 — Material and cost library
Add editable materials, quantities, and rough costing logic to provide basic estimates for improvements.

## Phase 3 — Failure event logic
Basic rules for determining likely failure points under various hazard categories.

## Phase 4 — Upload support
GLB/GLTF first, OBJ later, IFC/SketchUp later if feasible. Allow external model testing.

## Phase 5 — Solver integrations
Future integration with tools like Blender, Project Chrono/PyChrono, OpenSees, OpenFOAM, or CalculiX/Code_Aster to enable more precise physics and structural estimations.
