# FutolTech Roadmap

## Phase 0 — Repo foundation
Docs and sample data only.

## Phase 1 — Visual MVP
Basic 3D viewport, model builder placeholders, scripted hazard animation.

## Phase 2 — Material and cost library
Add editable materials, quantities, and rough costing.

## Phase 3 — Failure event logic
Basic rules for likely failure points.

## Phase 4 — Upload support
GLB/GLTF first, OBJ later, IFC/SketchUp later if feasible.

## Phase 5 — Solver integrations
Future integration with Blender, Project Chrono/PyChrono, OpenSees, OpenFOAM, CalculiX/Code_Aster.
