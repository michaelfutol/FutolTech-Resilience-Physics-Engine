# Specimen A0: 3m x 3m Sawali Test House

**Specimen ID**: A0
**Name**: 3m x 3m Sawali Test House

## Components
- 3m x 3m test module
- 1x1 inch / 25x25x1.5mm tubular frame
- Hardiflex backing wall
- Sawali or bamboo outer cladding
- Simple light roof
- Slab-on-grade or raised RC base option
- Screw/bolt/strap placeholders

## Expected Results
This baseline is not expected to pass extreme typhoon loading. Its main purpose is to serve as a test study to reveal likely first failure points and to establish the baseline for testing upgrade paths.
