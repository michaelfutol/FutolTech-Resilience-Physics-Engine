# Specimen A0: Demo 01

**Name:** 3m x 3m Sawali Test House
**Components:**
- 3m x 3m test module
- 1x1 inch / 25x25x1.5mm tubular frame
- Hardiflex backing wall
- Sawali or bamboo outer cladding
- Simple light roof
- Slab-on-grade or raised RC base option
- Screw/bolt/strap placeholders

**Expected Result:** The baseline is not expected to pass extreme typhoon loading. Its purpose is to reveal likely first failure points.
