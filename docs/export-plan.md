# RPE Export Plan

## Future Export Targets

In future phases, the FutolTech Resilience Physics Engine will support the following export formats and outputs:

- **MP4 Simulation Playback:** Video recording of the 3D viewport simulation.
- **PNG Screenshots:** High-resolution captures of the viewport, especially capturing highlighted weak points.
- **PDF Report:** A comprehensive engineering-style report summarizing the baseline structure, hazards applied, simulation sequence, identified weak points, and suggested upgrades.
- **CSV/JSON Cost Table:** An itemized breakdown of base materials, selected upgrades, and their individual/total costs.
- **Simulation Event Log:** A timestamped text/JSON file detailing each failure event as it occurred in the timeline.
- **Weak Point Map:** A visual top-down or 3D coordinate map of where stress/failures were detected.
- **Selected Upgrade List:** A structured list of all upgrades applied to the baseline structure.
- **Next Specimen Recommendation:** The algorithmic output suggesting the next viable engineering step (e.g. "A1 — Braced 3m x 3m Sawali Test House").
