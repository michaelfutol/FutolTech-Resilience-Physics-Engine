# Material Library

The material library holds definitions for the physical components used in the working specs.

## Current Placeholders
- 25x25x1.5mm tubular steel
- Hardiflex 6mm
- Sawali / bamboo cladding
- GI roofing sheet
- Anchor bolt placeholder
- Screw placeholder

These materials are intended to be editable by users in future phases to support customized testing and rough costing logic.
