# Project Overview

FutolTech Resilience Physics Engine is intended as a visual simulation and costing workspace for low-cost Filipino housing systems.

The goal is to allow users to build or upload simple 3D structures, assign realistic materials and connections, test them against various hazard scenarios (like typhoons, rain, debris, floods, heat, and seismic events), and subsequently visualize probable failure sequences and identify costed upgrade paths.

This system serves as an early discovery and visualization tool to help identify likely weaknesses in standard or modified traditional building methods, making it accessible to those examining basic structural resilience.
