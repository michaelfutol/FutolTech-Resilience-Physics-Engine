# Open-Source Stack Plan

The architecture is described as layered:
- **UI Layer (Currently Installed):** React / Next.js, Tailwind, TypeScript, Google Stitch MCP (for UI planning).
- **Visual Simulation Layer:** Three.js / React Three Fiber, Drei (currently installed as static conceptual 3D structure). Rapier.js / cannon-es (planned candidates, not yet installed).
- **Data Layer:** JSON-based material library, specimen library, etc.
- **Future Solver Layer:** Project Chrono / PyChrono, OpenSees, OpenFOAM, CalculiX / Code_Aster, Blender.
- **Report/Export Layer:** Placeholders for screenshots, video, report, and cost tables.
