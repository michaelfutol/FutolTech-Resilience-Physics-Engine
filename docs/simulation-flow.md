# Simulation Flow

The primary simulation workflow for the minimum viable product is designed to be visual and sequential.

## First MVP Flow
1. **Load/Create**: Create or load a working spec (e.g., 3m x 3m test house)
2. **Setup**: Assign materials and connections to the model
3. **Environment**: Choose a hazard category
4. **Execution**: Run the visual failure sequence
5. **Review**: Show the event timeline
6. **Analysis**: Identify likely weak points (failure map)
7. **Action**: Suggest the next improvement
8. **Estimation**: Show a rough cost impact placeholder
9. **Output**: Export report/video later

## Simulation Timeline Example
```text
00:00 — Wind loading begins
00:04 — Sawali outer cladding starts vibrating
00:09 — Hardiflex screws show stress at windward wall
00:14 — Roof edge uplift begins
00:19 — Frame racking exceeds limit
00:25 — First connection failure detected
00:31 — Model marked failed
```
