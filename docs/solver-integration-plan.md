# Solver Integration Plan

Future integrations, not immediate MVP tasks:
- **Project Chrono / PyChrono:** Higher-fidelity physics, multibody dynamics, contact, debris impact.
- **OpenSees:** Earthquake/seismic behavior, frame racking.
- **OpenFOAM:** Wind/CFD studies, pressure zones, roof suction.
- **CalculiX / Code_Aster:** Local stress checks, base plates, bracket analysis.
- **Blender:** Asset preparation, animation/rendering.
