# UI Concept

The initial user interface is intended to be practical and straightforward, providing a single cohesive workspace.

## MVP Layout
- **Left Panel**: Model tree and builder elements.
- **Center**: 3D viewport for the working spec and simulation visualization.
- **Right Panel**: Materials, connections, and hazard settings configuration.
- **Bottom Panel**: Simulation timeline and failure log.
- **Controls/Export**: Buttons for exporting video, screenshots, reports, and cost tables.
